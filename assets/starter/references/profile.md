# 个人档案（空白模板）

尚未录入使用者资料，不得将此模板或演示例子作为个人经历。

- 姓名 / 显示名：待填写
- 当前工作、学习或实践方向：按已提供内容记录，职业名称不限，未知可空
- 求职方向：待填写
- 电话 / 邮箱 / 作品链接：按需填写，未知省略
- 写作定位与语言：待填写

## 工作经历

填写真实单位、机构、客户服务或独立实践的归属、本人角色、起止日期、责任范围和来源。未知职称省略，兼职、实习、自由职业与内部流转保留真实关系，不要求按项目整理。

## 教育

填写学校、学历、专业、日期与来源；未提供时不要补造。

## 技能范围与写作偏好

仅填写有本人贡献支持的方法、工具与专业能力；环境和团队能力分开记录。目标方向由这里或本次请求确定。

教育之外的资格、培训、作品、研究、服务或其他经历，有材料时在本档案或 `career/` 下按内容建立记录，无需填满固定职业栏目。没有案例或代码资料时不要求补齐。
