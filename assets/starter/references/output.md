# 输出规范

先交付完整文字履历 `local/output/career/career.md` 与可维护的 `local/references/career/README.md` 及源记录，未知项和来源状态保留。网页与 Git 统计按需生成；空模板不算履历交付。

用户要求简历时，从最新履历交付完整 resume.zh-CN.md 或 resume.en.md，与独立 match-report.md；无 JD 也可生成通用版，局部精修按请求缩小范围。

正文采用清楚的公司 / 项目标题和日期，按问题、本人动作、机制、结果写项目条目。历史职称、责任程度和公司归属保持真实；未知非必要字段省略，不夹带来源 ID、匹配分数或待确认项。英文不增强中文原文职责，未提供公司官方英文名时保留原名或说明音译。

报告记录目标与假设、实际采用的履历基线、正文各实质条目与事实 ID / 来源状态的对应、项目选择、JD 或通用方向映射、删减项、缺口与必要问题。已确认事项不重复问；可省略的待确认项不阻塞可用内容。待确认、推测、已更正 / 撤回及排除条目不进入正文。

Word / PDF 按需使用当前环境工具，渲染检查分页并提取文本核对；无工具时交付 Markdown，不能声称完成两页排版或改扩展名伪装文档。

默认保存到私人资料目录 output/resumes/YYYY-MM-DD-方向/（新布局为 local/output/resumes/），日期按用户时区，已有版本加后缀；没有文件工具时在对话中交付并说明未落盘。生成不等于投递或上传授权。新确认先保存进履历再生成修订版；简历措辞不反向升级事实。
