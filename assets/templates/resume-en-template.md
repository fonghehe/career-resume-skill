Structural notes, not resume text — remove before export:

- Use `#` for the name, `##` for section headings and `###` for entries. In an entry, separate fields with `|` and put a complete date range last so the exporter right-aligns it. Omit the date segment entirely when unknown; never guess `Present`.

- Omit photos, date of birth, gender, marital status, nationality, salary expectations, referees and "References available upon request" unless the target country or the user explicitly requires them.
- Keep to one page for early-career profiles and at most two for senior profiles. The Markdown file has no page concept; the actual page count comes from the rendered DOCX / PDF.
- This skeleton is a content guide, not a fill-in form. Replace every `{{...}}` placeholder before running `scripts/career.py export`, which rejects placeholders.
