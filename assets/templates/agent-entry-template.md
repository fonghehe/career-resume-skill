# career-resume-skill 入口

将下面的内容加入宿主的项目规则或快捷指令，将两个占位路径替换为实际绝对路径。它只负责发现与路由，完整流程继续由 `SKILL.md` 维护。

```text
职业材料技能：career-resume-skill
用途：先从经历与材料维护完整职业履历，再从履历生成简历、依据报告或面试材料。
Skill 入口：【公共安装或完整工作副本的绝对路径】/SKILL.md
个人工作副本：【自己的完整工作副本绝对路径】

当我要求整理履历、更新职业经历、生成简历或准备面试时，读取上述入口。
已指定完整个人工作副本时，读取该副本的 SKILL.md 和已有资料，
以它为准读写 local/ 并运行其 scripts/，复用事实与来源。
缺少文件、附件读取或命令能力时说明限制，交付能完成的文字内容。
```
