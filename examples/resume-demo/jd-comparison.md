# 两个虚构岗位对比

> 虚构教学示例。候选人证据来自 [演示履历](career.md)。

- 岗位 A · 业务后台前端。JD 写明「须有 React、TypeScript 开发经验，负责表单开发与接口联调」。
- 岗位 B · Java 后端。JD 写明「须有独立实现 Java 服务端接口的经验，与前端协作」。

| 对照项 | 岗位 A · 业务后台前端 | 岗位 B · Java 后端 |
|---|---|---|
| 硬性条件 | E01-A 直接支持 React / TypeScript。 | 缺少本人独立实现服务端接口的证据。 |
| 主要职责 | E01-A 支持工单筛选与表单校验。E01-B 支持接口联调。 | E01-B 的联调经历可以支撑接口协作。 |
| 原文未说明 | 技术年限、团队规模。 | 框架、数据库、技术年限。 |

如果选择岗位 A，可把工单筛选和校验放在项目开头。如果继续考虑岗位 B，先确认用户是否有其他独立服务端开发记录。本次只生成对比。
