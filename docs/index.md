## 先整理，再选材

提供经历或材料，让智能体交付完整文字履历与可维护记录。随后补充事实，或根据最新履历生成通用 / 岗位简历；网页和 Git 统计按需添加。

无论职业名称是否出现在教学示例中，都可以从已有材料开始。既可以记录长期职责，也可以整理一件具体工作；没有项目就省略案例模块。转行、自由职业或跨领域记录继续保留真实归属，按当前目标选择可迁移经验。

## 三步使用

1. 打开自己的完整工作副本，让智能体读取 `SKILL.md`；个人资料集中在 `local/`。
2. 提供口述经历、旧简历或项目材料，先查看生成的完整文字履历；后续补充事实继续用同一份档案。
3. 先回顾各阶段的工作；需要求职时给出方向或岗位 JD，生成简历正文与独立依据报告。

日常不需要编辑 JSON 或启动教程站。网页、Git 与文档格式按实际需求添加。

日常操作从[快速开始](guide/quick-start.md)进入；已有正文直接看[导出中英文 Word / PDF](guide/export-resume.md)。开发者可查看[架构与职业扩展](reference/directories.md#运行流程与扩展)。
