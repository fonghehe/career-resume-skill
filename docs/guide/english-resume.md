# 英文简历与海外投递

同一份履历可以生成中文版和英文版。英文版不是把中文逐句机翻：内容按英语简历的习惯重写，版式也换成海外常用的单栏 ATS 友好样式，事实仍全部来自你的履历记录。

## 怎么提需求

```text
请读取 SKILL.md，复用当前 local/ 中的最新履历。
生成一份英文简历，面向美国的前端 / 全栈岗位，目前没有具体 JD。
排版用国际版式，导出 DOCX；公司名没有官方英文名的请标注待确认，
不要补造量化数据，也不要把参与写成主导。交付独立的依据报告。
```

也可以只要局部：

```text
把上一份中文简历的项目段落翻译成英文，保持参与程度和日期精度不变。
```

局部润色和翻译只处理指定文本，不会重建整份履历或生成新版本。想同时看中文与英文，可以分两次请求，两个版本各自保存到独立目录。

## 和中文版有什么不同

| 项 | 中文版（默认） | 英文国际版 |
|---|---|---|
| 页面 | A4 | 默认 US Letter；英联邦 / 欧洲可切 A4 |
| 分节标题 | 主题主色、浅色底、左侧竖线 | 黑色全大写、底部细线，无颜色 |
| 字体与行距 | 中文黑体 + Arial，正文 16.8 pt 精确行距 | 全篇 Arial，正文 14.4 pt 精确行距 |
| 联系方式 | 置顶一行 | 置顶一行，加城市 / 国家与可选主页链接 |
| 内容 | 个人优势、工作经历、项目经历等按需组合 | Professional Summary、Experience、Projects 等标准标题，动词开头的短 bullet |
| 不写 | 空栏目 | 照片、生日、性别、婚况、国籍、薪资、推荐人、未证实的语言等级 |

两版共用的规则不变：正文只采用已确认事实、精简投递版项目通常最多 3–4 个且先写业务难点、任职不因控页数被静默删掉、每个主张都能回到稳定事实 ID。完整的英文写作与版式参数在公共 `references/english-resume.md`。

## 导出 Word

```sh
python3 scripts/career.py export "local/output/resumes/2026-11-14-方向/resume.en.md" --layout international
# 英国、欧洲或明确要求 A4 时
python3 scripts/career.py export "…/resume.en.md" --layout international --page a4
```

同目录生成 `resume.en.docx`。`--layout standard` 是原来的中文主题色版式，文件名为 `resume.en.md` 时自动使用国际版式，其他文件名默认中文版式；`--theme` 在国际版会被忽略，因为海外 ATS 版式不使用主题色。用[本地工作台](workbench.md)下载时，文件名为 `resume.en.md` 的版本自动改用国际版式，主题选择只对中文版生效。

英文条目写成 `### Company | Title | Jan 2024 – Present`，末尾是完整日期区间才会右对齐；原记录只有年份时写 `2018 – 2022`，未知日期整段省略。PDF 从导出的 DOCX 转换，可加 `--format all` 同时生成 Word / PDF（需本机 LibreOffice），或在 Word 中另存 PDF，不要从 Markdown 另起排版源，转换后逐页检查行距、日期和分页。命令细节见[工具命令](../reference/commands.md)。

## 交付文件

| 文件 | 内容 |
|---|---|
| `local/output/resumes/YYYY-MM-DD-方向/resume.en.md` | 英文正文，标准 ATS 标题与条目结构 |
| 同目录 `resume.en.docx` | 国际版式 DOCX，可直接投递或另存 PDF |
| 同目录 `match-report.md` | 事实映射、译名待确认项、选材与删减、能力缺口、验证范围 |
| 同目录 `style.json` | 记录 `layout: international` 与页面尺寸 |

中文正文和英文正文分别保存，互不覆盖；旧版本也保留。

## 导出前检查清单

- 拼写体系统一（美式或英式），日期格式统一为 `Mon YYYY`，没有把年份精度补成月份；精确到日的短期区间可保留数字格式并在报告说明。
- 公司、学校、项目名用的是已确认的官方英文名，其余在报告里标为待确认。
- 每条 bullet 都是动词开头、写本人动作；参与没有被写成主导，项目环境没有变成个人技能。
- 没有照片、生日、性别、婚况、薪资、推荐人，也没有为凑页数编造指标。
- 联系方式只在正文首部，不在页眉页脚；没有双栏、表格、图标或文本框。
- DOCX 里分节标题是黑色大写细线样式，同类段落行距一致，日期右对齐且未被挤压。
- PDF 从 DOCX 转换后再次抽查；实际页数以渲染文件为准。

本项目能校验 DOCX 的结构、文本顺序和行距参数，但**没有实测任何第三方 ATS 系统**。如果目标公司有自己的投递系统，导入后请单独验收解析结果，别把「结构可解析」当成「已通过筛选」。

需要中文版或主题色版式，见[根据履历生成简历](generate-resume.md)。英文版同样不限行业：非软件职业的模块按职业与证据选择，规则在技能内的 `references/profession-workflow.md`，网页示例见[生成离线履历网页](generate-webpage.md)。
