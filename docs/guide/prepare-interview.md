# 从履历准备面试材料

已整理的履历可以复用为自我介绍、项目讲述、技术案例和可能追问。先核对最新事实与责任程度，再选择适合本次目标的内容。

```text
请读取 SKILL.md，复用当前最新履历。
我准备前端开发面试，请选两个有事实依据的项目，
整理自我介绍、项目讲述、方案取舍和可能追问。
每个主要主张对应已有条目，未知细节单独列出，不补造指标或职责。
请把材料保存到 local/output/interviews/ 的新版本目录。
```

提供 JD 可以按具体要求准备；没有 JD 就使用你说明的方向。只需要一段自我介绍或一个项目故事时，直接指定范围。

## 你会拿到什么

默认保存在 `local/output/interviews/YYYY-MM-DD-方向/preparation.md`，包括用户要求的自我介绍、项目背景、问题与约束、本人动作、机制或方案、取舍、有依据的结果与验证，以及可能被追问的内容。事实映射和缺口独立列在文末，讲述正文保持自然。

已经做过的项目事实可以进入讲述。未确认的根因、难点或方案只能标为补充问题；针对缺失能力的通用技术练习要与本人经历分开，不能把练习答案写成做过的事情。

## 想起更多细节时

```text
我补充了 P01-A 的当时约束与处理过程：【实际内容】。
请先保存这次陈述和确认范围，再修订项目讲述并保留旧版本。
```

新事实先进入履历，口语表达与精简不反向升级事实。面试材料不会自动修改现有简历；需要同步简历时再明确要求。

项目深入整理见[技术案例](project-cases.md)，事实维护见[补充与更正](update-career.md)。
