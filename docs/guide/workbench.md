# 在网页里编辑履历

想改日期、补项目职责、确认事实或另存简历，可以打开本地履历工作台。日常编辑由浏览器与 Python 工具完成。

## 打开自己的资料

在一直使用的完整工作副本里运行：

```sh
python3 scripts/career.py workbench
```

浏览器会打开工作台。页面顶部显示当前资料库，先确认这是你保存履历的目录。使用全局安装时，可以明确指定完整工作副本：

```sh
python3 /实际安装路径/scripts/career.py workbench --workspace /实际路径/my-career
```

终端需要保持运行，结束时按 Ctrl+C。默认自动选择本地端口；想保持浏览器草稿所在地址一致，可以加 `--port 8765`。使用 `--no-browser` 时，复制终端给出的完整地址打开。

## 先用有内容的示例试一下

```sh
python3 scripts/career.py workbench --demo
```

示例带有 2 家公司、3 个项目、项目阶段、提交记录和中英文简历版本。可以修改一段项目摘要，勾选本人确认，点击「检查并保存」，再刷新页面和查看修改历史。这份示例使用临时独立资料库，关闭服务后清理。个人资料库从普通启动命令进入。

## 修改任职或项目

1. 选择「工作经历」或「项目与案例」，再选一条记录。没有记录时点击「新增」。
2. 修改字段。技术和成果每行一项；阶段使用「日期 | 标题 | 说明」，每行一个阶段。
3. 确认真实事实时勾选「我确认本次选中的事实字段」。只想调整摘要的表达，可把本次修改改为「只改展示摘要／定位」。
4. 点击「检查并保存」，检查本次字段变化，再点击「保存到资料库」。

右侧会预览尚未保存的字段。新项目预览使用草稿卡片，保存后生成完整项目卡。日期支持 `YYYY`、`YYYY-MM` 或 `YYYY-MM-DD`；只有年或月时图上按该年或月的首尾展示，源记录保留原精度，未知起止同时留空。单位已知、职称未知时可留空，不必补造；清空事实字段会标为待确认，保留历史来源。

需要确认一个文字未变的字段时，展开该字段下的「确认状态与事实编号」，勾选确认。旧资料已有事实编号时填写该编号，例如 `P01-A`。新增字段默认分配稳定编号，以后修改继续复用。

## 原文、来源和恢复

「原文编辑」保留旧 Markdown 的自由写法。可以补充项目背景、方案取舍或处理待确认条目。项目摘要等表单字段通过表单修改；原文中的网页维护字段块保留原样。

事实修改会记录新来源和原值，在档案或项目卡中保存最新字段，并重建文字履历和网页。展示摘要的修改标为 `display-only`，后续写简历时需要回查事实。手工原文修改会保存原文快照，状态由你逐项维护。

「修改历史」可查看差异、恢复到某次修改前。文件已经有后续变化时，恢复会停止。多个页面或 Agent 同时改文件时，旧页面保存会提示重新载入。未保存草稿可在相同浏览器地址下恢复；资料基线已变时会导出草稿供核对。

## 选材与中英文 Word / PDF

在「简历版本」中选择任职、案例、教育资格等自定义模块或源记录，点击「从所选经历准备材料」。没有项目也可使用。结构化经历会组成待核对草稿，原文保留在材料区供智能体写作；自由记录不机械变成简历主张。英文选择只改变草稿提示语言，不会自动翻译材料。先让智能体核对来源、组织和翻译正文，补齐实际事实编号，再另存正文和报告。

已有版本可载入编辑，正文与依据报告一起另存。可选择两个版本比较，或输入更正的事实编号查看旧简历引用位置。简历版本页可选择晴空蓝、鼠尾草绿、雾紫、海盐青、杏桃橙主题；另存时主题随版本保存，载入后复用，也可换色下载。中文版本按所选主题色导出；**英文版本（`resume.en.md`）自动改用黑白国际版式**（US Letter，可在下载接口用 `page: a4` 切换），主题选择对英文版无效，文件名标注 `international`。选择已保存版本后可下载 DOCX 或 PDF；未保存的简历草稿须先另存。PDF 由同一 DOCX 经本机 LibreOffice 转换，缺少转换器会提示，DOCX 下载仍可用。下载后检查字体和分页，详见[导出教程](export-resume.md)。英文写作与国际版式规则见[英文简历与海外投递](english-resume.md)。

## 需要 Agent 时只准备相关材料

「交给 Agent」允许选择任职、案例、自定义模块或源记录，输入本次要求和可选 JD，生成可复制材料。只包含本次选择的内容，不要求项目；复制前可以检查。岗位分析、润色或新材料理解仍可交给 Agent。

首次从自由文本履历准备网页展示摘要，继续使用[生成网页教程](generate-webpage.md)。工作台会直接加载已有展示数据，旧 Markdown 可以从原文编辑器继续维护。

职业名称和经历模块均不限于示例。只有任职、学习或服务经历的人，也可以通过「原文编辑」维护 `references/career/` 中的记录，再从源记录选材。新增详细记录或网页模块可直接请智能体按事实流程建立，无需创建虚构项目。
